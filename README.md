How to Install

Click the puzzle piece icon in the top-right corner of Chrome.
1.  Click Manage extensions.
2.  Turn on Developer mode (top right).
3.    Click Load unpacked.
4.    Select the downloaded extension folder.


How to Add a Background Without Downloading:

Find a GIF or video you like.
1.    Right-click it and select Copy image link (or Copy video link).
2.    Open the Background Manager in the extension.
3.    Paste the link.
4.    Click Add link.
